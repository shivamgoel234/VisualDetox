# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Frontend engineers reviewing layout and contrast defects on a webpage. The bundled audits also support a portfolio walkthrough without provider credentials.

## Product Purpose

Turn a URL into an audit with browser measurements, a repaired HTML copy, and before-and-after evidence. Each live fix requires both measurable improvement and visual agreement.

## Operating Context

The first screen starts with a URL audit and a saved report. The result view provides desktop and mobile comparisons, an issue ledger, the HTML diff, a preview, and a download.

## Capabilities and Constraints

The server runs locally. Live runs use Gemini. Fixture mode evaluates archived demo repairs with browser measurements. Saved reports are available without credentials.
